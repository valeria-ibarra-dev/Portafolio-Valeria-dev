IA & Arquitectura

Plataforma SaaS Multi-tenant con IA Generativa

Plataforma de gestión de PQRS multi-tenant con Clean Architecture, integrando un módulo completo de IA: RAG con base de conocimiento propia, triaje automático de solicitudes y notificaciones en tiempo real.

ASP.NET Core PostgreSQL/pgvector Groq Ollama SignalR JWT AWS EC2 Docker
Ver código

Decisiones clave

  • RAG con PostgreSQL + pgvector: embeddings generados localmente vía Ollama, respuestas sintetizadas con Groq, búsqueda por similitud coseno con índices HNSW.
  • Módulo de triaje automático que clasifica solicitudes en tiempo real (tipo, prioridad, sentimiento, resumen) con salida JSON estructurada.
  • Aislamiento multi-tenant de doble mecanismo: API Key para integraciones públicas (widget embebible) y JWT con claims personalizados para usuarios autenticados.
  • Notificaciones en tiempo real con SignalR, segmentadas por grupos de tenant.
  • Despliegue completo en AWS EC2 desde cero: Security Groups, SSH, Docker Compose multi-servicio, Nginx, migraciones en producción.
  • Widget embebible en JavaScript vanilla con Shadow DOM para aislamiento total de estilos.

Full Stack

RentApp — Plataforma de Rentas Cortas

Plataforma full-stack que conecta huéspedes y propietarios, con validación de identidad por IA, prevención de doble reserva a nivel de base de datos y notificaciones automáticas.

Next.js 14 .NET 10 Clean Architecture PostgreSQL Redis Laravel Claude Vision API
Ver código

Decisiones clave

  • Clean Architecture en 4 capas (Domain → Application → Infrastructure → API), con las dependencias apuntando siempre hacia adentro.
  • Prevención de double-booking a nivel de base de datos con un EXCLUDE CONSTRAINT de PostgreSQL (extensión btree_gist), garantizando que dos reservas nunca se solapen aunque ocurran al mismo tiempo.
  • Validación de identidad (KYC) con Claude Vision API: el documento se cifra con AES-256, se analiza, y se elimina inmediatamente después del veredicto.
  • Autenticación diferida: el usuario explora y guarda favoritos sin registrarse; el login solo se pide al reservar.
  • Favoritos anónimos con Zustand y sincronización automática al iniciar sesión.
  • Microservicio de notificaciones en Laravel, desacoplado vía cola Redis, para no bloquear el flujo principal de la API.

Tickets API — Sistema de Soporte Técnico

API REST en Laravel para gestión de tickets de soporte y asignación de dispositivos, con monitoreo de errores, notificaciones automáticas y dashboard de métricas.

Laravel 11 PHP 8.4 SQL Server Sanctum Docker Sentry Discord Webhooks
Ver código

Decisiones clave

  • Autenticación con Laravel Sanctum vía tokens Bearer.
  • Rate limiting de 10 requests por minuto por IP/usuario, con respuesta 429 controlada.
  • Monitoreo de errores en producción con Sentry.
  • Notificaciones automáticas a Discord ante errores 500 o límites excedidos, con detalles del endpoint, método e IP.
  • Dashboard visual con métricas de tickets, dispositivos y actividad reciente.
  • Logs personalizados por evento (creación, actualización y eliminación de tickets, asignación de dispositivos).
Producto & IA

Wayze — Planificador Inteligente de Rutas

Aplicación de ciudad inteligente para Medellín que combina clima, seguridad ciudadana y agenda diaria con IA para sugerir la mejor ruta. Presentado en el RIWI Tech & Business Showcase, Advanced Track.

React 18 ASP.NET Core 8 FastAPI OpenAI n8n PostgreSQL Google Maps API
Ver en GitHub

Decisiones clave

  • Microservicio independiente en FastAPI (Python) para el pipeline de IA: parsea la agenda en lenguaje natural y calcula un puntaje de seguridad por ruta.
  • Integra tres fuentes de datos externas en un solo flujo: Google Maps (rutas), OpenWeatherMap (clima por segmento) y datos.gov.co (seguridad ciudadana por zona).
  • Automatización con n8n para recordatorios inteligentes vía WhatsApp y email.
  • Arquitectura poliglota: React para el frontend, ASP.NET Core como API principal, FastAPI para IA — cada servicio en su propio repositorio.
  • Documentación técnica completa con diagramas de arquitectura, ERD de base de datos y flujo de usuario.
